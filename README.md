# gigi-mockups

Interactive HTML mockups for Salesforce and product design discussions.

## GitHub Pages structure

The repository homepage is served from `/index.html`.

Each mockup lives in its own folder and uses an `index.html` file. This creates clean URLs such as:

- `/support/guided-response/`
- `/support/request-additional-information/`
- `/governance/send-for-review/`
- `/governance/review-approval/`
- `/governance/evaluated-record-audit/`

For a project site, the final address follows this pattern:

`https://<github-user>.github.io/gigi-mockups/<mockup-path>/`

Publish GitHub Pages from the `main` branch and the repository root.
